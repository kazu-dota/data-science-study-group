# 第1回：データ分析の準備

この回は次の4パートで構成します。

- **パート1：Python環境とuv、Gitの基礎** — 自分のパソコンで、なぜ同じPythonの環境を再現できるのか。
- **パート2：Pythonを読み、Copilotと少し変える** — 分からないコードを、どうやって小さく理解し、安全に書き換えるか。
- **パート3：pandasで表データに触る** — 初めて見る表データを受け取ったら、最初に何を見るか。
- **パート4：分布・欠損・外れ値を確認する** — モデルを作る前に、データの怪しいところをどう見つけるか。

## 進め方

パート1→2→3→4の順に、「基本」と「演習」を進めます。1日で全部を終える必要はありません。「発展（任意）」と「追加演習（任意）」は余裕がある場合だけ取り組みます。

実習は [lesson.ipynb](lesson.ipynb) を使います。詳しい進め方は [README「Notebookの進め方」](../../README.md#notebookの進め方) を参照してください。

Python環境（uv・Conda）やGitの仕組みをもっと知りたい人は、[Python環境とGitの基礎（任意）](../../docs/environment-and-git-basics.md) を参照してください。必須ではありません。
