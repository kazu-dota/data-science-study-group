# 第5回：何を、いつ、何のために予測するか

**今日の問い**：モデル構築より前に決めるべきことは何か。

## 90分

- 10分：同じデータから異なる予測問題を作る
- 20分：目的、予測時点、目的変数、説明変数を整理する
- 20分：平均値・最頻値のベースラインを作る
- 25分：`TRY` 化学研究の例を5人で問題設定する
- 10分：予測時点で使えない列を探す
- 5分：最も試したい設定を選ぶ

## ASK COPILOT

```text
以下の研究課題を予測問題として整理してください。
目的、予測時点、目的変数、利用できる説明変数、利用してはいけない情報、
回帰か分類か、という見出しで、不明点は質問にしてください。
```
