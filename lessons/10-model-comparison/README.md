# 第10回：モデル対決

**今日の問い**：複雑なモデルは本当にいつも優れているか。

## この回の深掘り

- `CORE`：5モデルを同じ分割・同じF1・同じ計測方法で比較する
- `DEEP DIVE`：5-fold交差検証の平均・標準偏差・最低F1を見る
- `SELF-STUDY`：説明重視と性能重視の用途で別々の推奨モデルを選ぶ

## 90分

- 10分：同じ問題へ5つの実験を割り当てる
- 20分：比較条件を揃える
- 30分：`TRY` 5人が異なるモデル・設定を試す
- 15分：スコア、時間、説明しやすさを並べる
- 10分：失敗例から次の一手を考える
- 5分：今日の勝者ではなく用途別候補を決める
