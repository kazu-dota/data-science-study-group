# 第3回：モデルの評価方法

この回は次の3パートで構成します。

- **パート1：モデルは本当に当たっているか** — 手元のスコアをどこまで信じてよいか。
- **パート2：クラスを予測する—分類** — 正解率だけで十分なのはどんなときか（AUCとLoglossの違いも扱います）。
