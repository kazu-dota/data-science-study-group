# 全5回の教材

最初に[Quickstart](../quickstart.ipynb)を動かしてから、第1回へ進みます。
各Notebookは上から順に実行できます。
Notebookの前後に[外部資料の指定範囲](../docs/resources.md)を読み、確認問題と追加演習にも取り組みます。

| 回 | 内容 | Notebook |
|---:|---|---|
| 1 | Pythonの基礎、NumPy、pandas | [開く](01-python-pandas-numpy/lesson.ipynb) |
| 2 | 機械学習、分類、回帰 | [開く](02-machine-learning-basics/lesson.ipynb) |
| 3 | 決定木、Random Forest、GBDT | [開く](03-advanced-models/lesson.ipynb) |
| 4 | 分類・回帰の評価、交差検証 | [開く](04-model-evaluation/lesson.ipynb) |
| 5 | 特徴量、設定探索、しきい値調整 | [開く](05-performance-improvement/lesson.ipynb) |

自分で値やコードを変える場合は、Notebookを`workspace`へコピーしてください。
元の教材を残しておくと、分からなくなったときにやり直せます。

全体の進行例は[全5回の進め方](../docs/course-plan.md)を参照してください。
