# 第2回：データを見て、問いを立て、評価を正しく設計する

この回は次の3パートで構成します。

- **パート1：分布・欠損・外れ値を確認する** — モデルを作る前に、データの怪しいところをどう見つけるか。
- **パート2：何を、いつ、何のために予測するか** — モデル構築より前に決めるべきことは何か。
- **パート3：モデルは本当に当たっているか** — 手元のスコアをどこまで信じてよいか（検証とデータリーク）。

## 進め方

パート1→2→3の順に、「基本」と「演習」を進めます。1日で全部を終える必要はありません。「発展（任意）」と「追加演習（任意）」は余裕がある場合だけ取り組みます。

実習は [lesson.ipynb](lesson.ipynb) を使います。詳しい進め方は [README「Notebookの進め方」](../../README.md#notebookの進め方) を参照してください。
