# 第7回：数値を予測する—回帰

**今日の問い**：連続値の予測モデルを、何と比べればよいか。

## この回の深掘り

- `CORE`：Dummyを含む4モデルをMAE・RMSE・R²で比較する
- `DEEP DIVE`：系列別MAEと平均残差から系統的な誤りを探す
- `SELF-STUDY`：誤差の大きさを実験判断の許容範囲と結びつける

## 90分

- 10分：回帰の予測例を挙げる
- 20分：Dummy、線形回帰、木モデルを実演する
- 25分：`TRY` MAE、RMSE、R²を比較する
- 20分：予測対実測と残差を可視化する
- 10分：最も外した試料を5人で調べる
- 5分：次に変える要素を1つ決める

## ASK COPILOT

```text
MAE、RMSE、R²の違いを、測定値の予測を例に説明してください。
外れ値がある場合に各指標がどう変わるかも説明してください。
```
