# 第15回：Show & Tell

**今日の問い**：自社データで始めるなら、最初の小さな一歩は何か。

## この回の深掘り

- `CORE`：目的・検証・結果・失敗・次の一歩を5分で共有する
- `DEEP DIVE`：用途、評価、限界、禁止条件、再現手順をモデルカードへまとめる
- `SELF-STUDY`：30日以内のデータ棚卸し・ベースライン・レビューを計画する

## 90分

- 10分：最終Notebookを最初から再実行する
- 35分：1人5分で面白かった図・改善・失敗を紹介する
- 20分：自社テーマ候補を1枚に整理する
- 15分：予測時点、評価方法、利用できない情報を相互レビューする
- 10分：次に試す小さなプロトタイプを話す

## ASK COPILOT

```text
以下の自社テーマ案を、目的、予測時点、利用者、目的変数、説明変数候補、
評価方法、リーク候補、最初の小さな実験という見出しで整理してください。
機密情報は含まれていません。不明点は質問にしてください。
```
