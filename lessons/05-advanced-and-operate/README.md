# 第5回：転移学習・再学習・ニューラルネットワークモデルの紹介

この回は次の3パートで構成します。

- **パート1：ニューラルネットワークを試す** — 複雑なモデルは、このデータでも必ず勝つのか。
- **パート2：転移学習を知る** — 少ないデータしかないとき、他所で学んだ知識を借りられないか。
- **パート3：モデルを運用する（永続化・監視・再学習）** — モデルを「作って終わり」にしないために、運用で何をするか。

## 進め方

パート1→2→3の順に、「基本」と「演習」を進めます。1日で全部を終える必要はありません。「発展（任意）」と「追加演習（任意）」は余裕がある場合だけ取り組みます。

実習は [lesson.ipynb](lesson.ipynb) を使います。詳しい進め方は [README「Notebookの進め方」](../../README.md#notebookの進め方) を参照してください。

Kaggleを実際に使ってみたい人は、任意教材の [titanic_optional.ipynb](titanic_optional.ipynb)（[ガイド](../../docs/kaggle-titanic-guide.md)）で試せます。
