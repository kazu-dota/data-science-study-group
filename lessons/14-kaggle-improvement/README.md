# 第14回：Kaggle改善会

**今日の問い**：限られた時間で、次に何を試すか。

## 90分

- 10分：ベースラインと分割方法を固定する
- 10分：5人へ異なる改善案を割り当てる
- 35分：`TRY` 1要素だけ変更して検証する
- 15分：改善・悪化の両方を共有する
- 15分：良かった変更を統合して再提出する
- 5分：再現可能かを確認する

## ASK COPILOT

```text
現在のベースラインと実験履歴を示します。
まだ試していない改善案を、前処理、特徴量、モデル、エラー分析に分けてください。
Leaderboardだけに合わせる提案は避けてください。
```
