# 第4回：データ探偵

**今日の問い**：モデルを作る前に、データの怪しいところをどう見つけるか。

## この回の深掘り

- `CORE`：分布、二変量関係、欠損、外れ値候補を順に見る
- `DEEP DIVE`：相関ヒートマップと群別欠損率を確認する
- `SELF-STUDY`：外れ値を残す場合と除く場合の影響、確認先を整理する

## 90分

- 10分：良いグラフと読みにくいグラフを比べる
- 20分：分布、関係、カテゴリ比較を実演する
- 30分：`TRY` ヒストグラム、散布図、箱ひげ図を作る
- 15分：欠損または外れ値を1つ調べる
- 10分：データから仮説を1つ共有する
- 5分：次回まで残したい問いを書く

## ASK COPILOT

```text
目的変数と数値列・カテゴリ列の関係を見るためのグラフ候補を、
確認したいこと、適したグラフ、注意点の3列で提案してください。
```
