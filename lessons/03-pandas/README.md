# 第3回：pandasで表データに触る

**今日の問い**：初めて見る表データを受け取ったら、最初に何を見るか。

## この回の深掘り

- `CORE`：形、型、欠損、要約統計、条件抽出を確認する
- `DEEP DIVE`：欠損率と一意数の品質表、触媒×溶媒の二軸集計を作る
- `SELF-STUDY`：件数・平均・標準偏差を一緒に読み、群間差を仮説として書く

## 90分

- 10分：CSVとDataFrameの関係を確認する
- 20分：`head`、`shape`、`dtypes`を実演する
- 30分：`TRY` 行・列の選択、条件抽出、集計
- 15分：5人で列を分担して調べる
- 10分：列の意味と怪しい値を共有する
- 5分：`CHALLENGE` groupbyを試す
