# 第8回：クラスを予測する—分類

**今日の問い**：正解率だけで十分なのはどんなときか。

## 90分

- 10分：陽性・陰性の判定例を考える
- 20分：混同行列を実演する
- 25分：`TRY` accuracy、precision、recall、F1を計算する
- 20分：判定閾値を変える
- 10分：偽陽性と偽陰性のコストを話す
- 5分：目的に合う指標を選ぶ

## ASK COPILOT

```text
混同行列、適合率、再現率を、化合物の活性有無を予測する例で説明してください。
偽陽性と偽陰性が研究計画へ与える影響も分けてください。
```
