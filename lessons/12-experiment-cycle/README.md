# 第12回：改善実験を小さく回す

**今日の問い**：改善した理由を後から説明できる実験とは何か。

## この回の深掘り

- `CORE`：1要素だけ変え、交差検証の平均とばらつきを記録する
- `DEEP DIVE`：holdout上のpermutation importanceを計算し、学習データ上の説明と分ける
- `SELF-STUDY`：実験ログをCSVへ保存し、重要度上位列のアブレーションを行う

## 90分

- 10分：一度に多くを変えた失敗例を見る
- 20分：交差検証とスコアのばらつきを実演する
- 25分：`TRY` 1要素だけ変えた実験を記録する
- 20分：permutation importanceとエラーを見る
- 10分：次の実験候補を優先順位づけする
- 5分：Kaggleで最初に使うパイプラインを選ぶ

## ASK COPILOT

```text
以下の実験結果から、次に試す変更を3つ提案してください。
期待する理由、変更箇所、比較条件、悪化した場合に分かることを示してください。
一度に1要素だけ変更してください。
```
