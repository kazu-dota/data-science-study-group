# 第11回：化学の知識を特徴量にする

**今日の問い**：研究者の知識を、モデルへ渡せる形にするにはどうするか。

## この回の深掘り

- `CORE`：化学的仮説を計算式へ変え、追加前後を比較する
- `DEEP DIVE`：特徴量を1つずつ足すアブレーションで寄与を分ける
- `SELF-STUDY`：式・期待方向・反証条件を先に記録してから新しい特徴量を作る

## 90分

- 10分：元データから作れそうな特徴量を挙げる
- 20分：比、差、合計、カテゴリ化を実演する
- 25分：`TRY` 1人1つの特徴量を作る
- 20分：同じ検証条件で追加前後を比較する
- 10分：RDKit記述子または計算済み記述子を見る
- 5分：意味が説明できる特徴量を1つ残す
