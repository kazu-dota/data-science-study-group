# 第4回：モデルを比較し、特徴量と実験で改善する

この回は旧カリキュラムの3回分をまとめた長い回です。次の3パートで構成します。

- **パート1：モデル対決** — 複雑なモデルは本当にいつも優れているか（公平な比較）。
- **パート2：化学の知識を特徴量にする** — 研究者の知識を、モデルへ渡せる形にするにはどうするか。
- **パート3：改善実験を小さく回す** — 改善した理由を後から説明できる実験とは何か。

## 進め方

パート1→2→3の順に、各パートの`CORE`（本線）で手を動かします。1回の時間で全部を終える必要はありません。各パートの`DEEP DIVE`／`APPENDIX`は、余裕のある人や自習で進めてください。

実習は [lesson.ipynb](lesson.ipynb) を使います。記号（`CORE`・`DEEP DIVE`など）の意味は [README「Notebookの目印」](../../README.md#notebookの目印) を参照します。
