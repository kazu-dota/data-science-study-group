# 全5回の進め方

## 開始前：まず完成形を動かす

[Quickstart](../quickstart.ipynb)を上から順に実行します。
全5回で扱うコードが1本につながっていることと、最後に予測結果が出ることを確認します。
この段階でコードを全て理解する必要はありません。

## 1回の進め方

各回は90分を目安にします。

| 時間 | 内容 |
|---:|---|
| 0〜10分 | 今日できるようになることを確認する |
| 10〜30分 | 講師と一緒にNotebookを動かす |
| 30〜65分 | 各自でコードを実行し、値を1つ変える |
| 65〜80分 | 結果の違いと理由を話す |
| 80〜90分 | 今日分かったことを1つ書く |

止まった場合は、前のセルから順に実行し直します。5分で解決しない環境問題は講師が控え、
参加者は講師PCの結果を見ながら本題を続けます。

## 第1回：Pythonの基礎とpandas・NumPy

**到達点**：短いPythonコードを読み、表データから必要な行や集計結果を取り出せる。

- 変数、リスト、繰り返し、関数を使う
- NumPyの配列で計算する
- pandasでCSVを読み、確認・抽出・集計する
- 欠損値を確認する

最後に、抽出条件や集計する列を1つ変えて結果を比べます。

## 第2回：scikit-learnと機械学習

**到達点**：分類と回帰の違いを説明し、学習と予測の基本コードを実行できる。

- 特徴量と目的変数を分ける
- 学習用と検証用のデータを分ける
- 数値を予測する回帰を試す
- クラスを予測する分類を試す
- 単純な予測と比べる

モデル名の暗記より、`fit`へ渡すものと`predict`から返るものを確認します。

## 第3回：高度な予測モデル

**到達点**：決定木、Random Forest、GBDTを同じ条件で比べられる。

- 1本の決定木を動かす
- 複数の木を使うRandom Forestを動かす
- GBDTが前の誤りを順に補う様子を見る
- 学習率や木の数を変える
- 任意でXGBoostを試す

複雑なモデルが必ず良いとは限らないことを、検証結果で確かめます。

## 第4回：予測モデルを評価する

**到達点**：1つの点数だけで判断せず、用途に合う指標と検証方法を選べる。

- 分類の適合率、再現率、F1、混同行列を読む
- しきい値を変えて誤り方の変化を見る
- 回帰のMAE、RMSE、R²を読む
- 残差が大きいデータを確認する
- 交差検証で結果のばらつきを見る

偽陽性と偽陰性のどちらを減らしたいかを、利用場面から考えます。

## 第5回：性能を向上させる

**到達点**：比較条件をそろえ、改善案を1つずつ試して記録できる。

- 役立ちそうな特徴量を作る
- `RandomizedSearchCV`で設定を探す
- 学習に使っていない予測でしきい値を決める
- 特徴量を並べ替えて重要度を調べる
- 変更前後を同じ指標で比べる

一度だけ高い点数が出たことを改善とはしません。変更点、結果、次に試すことを残します。

## 終了後：別のデータで試す

[Appendix](../appendix/)から興味のあるものを1つ選びます。
画像、音声、文章でも、全5回と同じ学習と評価の流れが使えることを確認します。
