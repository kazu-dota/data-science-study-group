# 講師用進行ガイド

## 開講前

次のコマンドを実行し、Quickstart、全5回、Appendixの全Notebookが完走することを確認します。

```powershell
uv sync
uv run python scripts/check_environment.py
uv run python scripts/validate_materials.py --execute
```

参加者には、最初に[Quickstart](../quickstart.ipynb)を動かしてもらいます。
環境構築の説明を長く続けず、早い段階で予測結果を見せてください。

## 毎回の進め方

Notebookは最低限の実習です。背景知識は[外部資料の学習ガイド](resources.md)を使います。
資料全体を宿題にせず、「ここから」「ここまで」で指定した範囲と確認問題を事前に共有します。

1. 開催前に外部資料の見出しとリンクが変わっていないか確認する
2. 今日のNotebookを講師PCで最後まで実行しておく
3. 外部資料の確認問題と、分からなかった言葉を共有する
4. 参加者とNotebookを上から順に実行する
5. 何を入力し、何が出力されたかを確認する
6. 値を1つだけ変えて結果を比べる
7. 追加演習と提出方法を確認する

120分の時間配分は[全5回の進め方](course-plan.md#勉強会120分の進め方)にまとめています。

専門用語は、Notebookで必要になったときに説明します。
数式や仕組みの詳しい説明は、コードの入出力を確認した後に行います。

## 各回で確認すること

| 回 | 全員で確認する出力 | 変更して試すもの |
|---:|---|---|
| 1 | 表の先頭、行数、列別の集計 | 抽出条件または集計列 |
| 2 | 回帰の誤差、分類の正解率 | 特徴量または分割比率 |
| 3 | 3モデルの比較表 | 学習率または木の数 |
| 4 | 混同行列、複数の評価指標 | 分類のしきい値 |
| 5 | 改善前後の比較結果 | 特徴量または探索範囲 |

第2回以降も、前回の内容を全て覚えている前提にはしません。
必要なコードはNotebook内に残し、短く読み直してから新しい内容へ進みます。

外部資料を読み切れなかった参加者もNotebook実習には参加できます。
確認問題で詰まった箇所を把握し、必要な見出しだけ一緒に読み直します。

## 初めての人が止まりやすい場所

- Notebookのセルを途中から実行している
- カーネルが`.venv\Scripts\python.exe`ではない
- ZIP内のファイルを展開せずに開いている
- 教材フォルダの外からNotebookを実行している
- エラーメッセージの最後の行だけを見ている

まず前のセルから順に実行し直します。解決しない場合はエラー全文と実行したセルを控え、
講師PCの画面で本題を続けます。

## 結果を共有するとき

次の3点だけを話してもらいます。

```text
変えたもの：
結果：
次に確かめたいこと：
```

スコアの高低だけでなく、なぜ変わったと思うか、別のデータでも同じかを確認します。

## Appendix

全5回の終了後、参加者が興味を持ったテーマを1つ選びます。
画像・音声・文章の専門知識を先に講義せず、まずNotebookを動かして入出力を確認します。
